# Contribuer

Commun est un bien commun numérique sous licence **AGPL v3** — les contributions sont bienvenues.

## Mise en place

Prérequis : [Bun](https://bun.sh) ≥ 1.1.

```sh
git clone https://github.com/commun-app/commun && cd commun
bun install
bun run dev          # API en dev (données sandbox dans .data/)
```

## Structure

| Chemin | Rôle |
|---|---|
| `packages/core` | Domaines métier, schéma Drizzle (SQLite via `bun:sqlite`), routers tRPC |
| `apps/api` | Shell Nitro v3 : montage tRPC, routes REST publiques, middleware |
| `e2e/` | Tests de bout en bout (Playwright + Gherkin) |

Conventions : code et identifiants **en anglais**, messages destinés aux utilisateurs **en français** ; un domaine = schéma + validation Zod + queries + router tRPC ; toute nouvelle surface d'API passe par tRPC (le plan REST public est volontairement minimal).

## Vérifications avant PR

```sh
bun run typecheck
bun run test
./scripts/check-naming.sh
```

Le workflow specs (OpenSpec) documente chaque changement de comportement : ouvrez une issue ou une discussion avant les gros chantiers.
