# Bienvenue

Commun est le CMS open source (AGPL v3) des communes et collectivités françaises : site public généré statiquement, actualités, agenda, élus, projets, délibérations, formulaires citoyens — auto-hébergeable en quelques minutes.

::alert{type="info"}
Documentation en construction — le guide d'auto-hébergement, la référence des variables d'environnement, le guide de sauvegarde/restauration et le guide contributeur arrivent avec la phase 1 (change `scaffold-monorepo`).
::

## Démarrage rapide (développement)

```sh
bun install
bun run dev
# API : http://127.0.0.1:3001 (health: /health)
```
