# Bienvenue

Commun est le CMS open source (AGPL v3) des communes et collectivités françaises : site public statique, contenus flexibles (actualités, agenda, élus, projets, et vos propres collections) — auto-hébergeable en quelques minutes. Les modules délibérations (avec transcription IA) et formulaires citoyens arrivent dans les phases suivantes de la feuille de route.

- **Single-tenant** : une instance = une collectivité (sa base SQLite, ses médias, son serveur).
- **Contenu flexible** : les contenus standards sont des collections par défaut (news, events, officials, projects) que vous pouvez adapter, et vous créez librement les vôtres.
- **Souverain** : hébergeable en France, aucun service propriétaire requis.

## Démarrage rapide (développement)

```sh
bun install
bun run dev
# API : http://127.0.0.1:3001 (health: /health, tRPC: /api/trpc)
```

Pour héberger une instance, suivez le [guide d'auto-hébergement](/guide/self-hosting).
